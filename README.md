# Codveda Task 1 — Luxe Landing Page

A responsive and modern landing page created as part of the
Codveda Technologies Front End Development Internship.

## Project Overview

This project demonstrates the implementation of a responsive
landing page using HTML, CSS, and JavaScript.

The design focuses on:

- Responsive web design
- Modern UI
- Elegant typography
- Interactive navigation
- Mobile-friendly layout
- Smooth scrolling
- Hover effects
- Clean and reusable CSS
- Responsive breakpoints

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Features

### Responsive Navigation

The navigation automatically changes into a mobile menu
on smaller screens.

### Hero Section

The hero section introduces the brand with:

- Main heading
- Supporting description
- Call-to-action buttons
- Decorative visual card

### About Section

Provides a short description of the design philosophy.

### Services Section

Displays three service cards:

1. Web Design
2. Development
3. Brand Identity

### Call To Action

A dedicated CTA section encourages users to get in touch.

### Footer

Contains:

- Brand logo
- Copyright information
- Privacy link
- Terms link

## Responsive Design

The website is optimized for:

- Desktop
- Tablet
- Mobile

CSS media queries are used to adapt the layout to different
screen sizes.
